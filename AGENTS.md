# Repository instructions

This repository contains small, independent Python tools for Team Bath Racing Electric engineering work. Each active project lives under `projects/` and has its own `AGENTS.md`, README and dependency instructions. Work from the relevant project directory and read only that project's files unless a shared change is required.

Use clear names, document engineering units and assumptions, and preserve the distinction between measured data, model assumptions and calculated outputs. Run the project’s documented checks after changes; add tests only where useful for the calculation being changed. Keep dependencies project-local. Put code in `shared/` only after a real need for reuse appears.

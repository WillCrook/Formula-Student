# Tyre-load analysis

This is an early project scaffold containing vehicle parameters in a `Tyre_Loads` class. It does not yet calculate tyre loads. Several parameter comments indicate uncertain definitions, so validate values and units before using them in an engineering model.

The current source is [`src/Tyres_and_Suspension_Members.py`](src/Tyres_and_Suspension_Members.py). See [`AGENTS.md`](AGENTS.md) for its present scope and development guidance.
